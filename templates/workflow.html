This is an optional step to convert the raw Bruker files to .mzML format. The next step (Step 1) requires renamed .mzML files with the following naming: Samplenumber_spotnumber (e.g. DC15000_A1.mzML). Renaming the files is necessary for averaging the technical replicates. Thus, the replicates of the same sample should have the same unique identifier (i.e., DC15000, in the example) and the associated spots (e.g., _A1, _D1, _G1).

Renaming is not done automatically: the converter keeps the file names produced by MALDIquantForeign, so rename the downloaded files before uploading them in Step 1.
